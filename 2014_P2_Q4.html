DSE 2014 · 卷二 · Q4

二次方程的判別式

題目

設 $a$ 為常數。若二次方程\n\[ x^{2}+ax+a=1 \]\n有等根，則 $a=$
  1. A$-1$
  2. B$2$
  3. C$0$ 或 $-4$
  4. D$0$ 或 $4$

題解

第 1 步
先化為標準式
二次方程標準式 \(ax^{2}+bx+c=0\) 「等根」是對標準式的係數說的，所以先把所有項移到同一邊。
把 $1$ 移到左邊： \[ x^{2}+ax+a-1=0. \] 與 $x^{2}+bx+c=0$ 對照，
得 \[ b=a,\qquad c=a-1. \] 注意 $x^{2}$ 的係數是 $1$，不是 $a$；$a$ 只是 $x$ 項的係數。
第 2 步
等根即判別式為零
判別式 \(\Delta=b^{2}-4ac\) 二次方程有等根（重根）的充要條件是 $\Delta=0$。
代入 $b=a$、$c=a-1$： \[ \Delta=a^{2}-4(1)(a-1)=0. \] 展開： \[ a^{2}-4a+4=0. \] 若 $\Delta>0$ 會有兩個相異實根，$\Delta<0$ 則無實根，
兩者都不合「等根」。
第 3 步
解出 $a$
完全平方 \((a-b)^{2}=a^{2}-2ab+b^{2}\) $a^{2}-4a+4$ 剛好是 $(a-2)^{2}$，所以判別式只有一個零點。
認出完全平方： \[ a^{2}-4a+4=(a-2)^{2}=0. \] 因此 \[ a-2=0,\qquad a=2. \] 只有一個 $a$ 值使判別式為零，
所以答案是單一數而不是兩個。
對照選項，答案為 B。
答案B（$a=2$）
練習 同類新題
題目. 若二次方程 $x^{2}+(k+1)x+9=0$ 有等根，則 $k$ 的可能值為
  1. A$5$
  2. B$-7$
  3. C$5$ 或 $-7$
  4. D$-5$ 或 $7$
顯示題解
第 1 步. 等根要求判別式為零：$(k+1)^{2}-4(1)(9)=0$。
第 2 步. 即 $(k+1)^{2}=36$，開方得 $k+1=6$ 或 $k+1=-6$。
第 3 步. 故 $k=5$ 或 $k=-7$，答案 C。
答案：C（$5$ 或 $-7$）
