DSE 2017 · 卷二 · Q5

逐條解，再取聯集

不等式 · 複合條件（或）

題目

$6-x\lt 2x-3$ 或 $7-3x>1$ 的解是
  1. A$x\lt 2$
  2. B$x>3$
  3. C$2\lt x\lt 3$
  4. D$x\lt 2$ 或 $x>3$

題解

第 1 步
先解第一條不等式
移項 \(6-x\lt 2x-3\) 把含 $x$ 的項移到同一邊，常數移到另一邊，過程中沒有乘除負數，不等號方向不變。
\[6-x\lt 2x-3 \ \Longrightarrow\ 6+3\lt 2x+x \ \Longrightarrow\ 9\lt 3x \ \Longrightarrow\ x>3.\] 所以第一條條件等價於 $x>3$。
第 2 步
再解第二條不等式
除以負數要反號 \(-3x>-6\iff x\lt 2\) 兩邊同除以 $-3$ 時，不等號要由 $>$ 變成 $\lt $。
\[7-3x>1 \ \Longrightarrow\ -3x>1-7=-6 \ \Longrightarrow\ x\lt \frac{-6}{-3}=2.\] 所以第二條條件等價於 $x\lt 2$。
第 3 步
「或」代表聯集
聯集 \(x\lt 2\ \text{或}\ x>3\) 只要滿足其中一條就可以，所以兩段都要保留，不需要找重疊部分。
兩條條件的解分別是 $x>3$ 與 $x\lt 2$，用「或」連接，取它們的聯集： \[x\lt 2\quad\text{或}\quad x>3.\] 在數線上就是「左邊一段」加「右邊一段」。 答案為 D。
選項 C（$2\lt x\lt 3$）是把「或」誤當成「且」的結果：$x\lt 2$ 與 $x>3$ 根本沒有交集，
所以若是「且」，答案是「無解」而不是 $2\lt x\lt 3$。
答案D（$x\lt 2$ 或 $x>3$）
練習 同類新題
題目. $3x-2>7$ 或 $5-x>4$ 的解是
  1. A$x\lt 1$
  2. B$x>3$
  3. C$1\lt x\lt 3$
  4. D$x\lt 1$ 或 $x>3$
顯示題解
第 1 步. $3x-2>7\Rightarrow3x>9\Rightarrow x>3$。
第 2 步. $5-x>4\Rightarrow-x>-1\Rightarrow x\lt 1$（兩邊乘 $-1$，反號）。
第 3 步. 取「或」的聯集：$x\lt 1$ 或 $x>3$，答案 D。
答案：D（$x\lt 1$ 或 $x>3$）
