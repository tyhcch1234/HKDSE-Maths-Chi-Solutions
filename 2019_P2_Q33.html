DSE 2019 · 卷二 · Q33

由左至右標位值，再把高位的項抽出 $2^{10}$

數制 · 二進位與位值

題目

把二進位數寫成指數形式：

$$100110000010110_{2}=$$

  1. A$19\times 2^{10}+22$
  2. B$19\times 2^{10}+44$
  3. C$19\times 2^{11}+22$
  4. D$19\times 2^{11}+44$

題解

第 1 步
數清位數，定出最高位的位值
二進位的位值 \((b_{k}\cdots b_{1}b_{0})_{2}=b_{k}2^{k}+\cdots+b_{1}2^{1}+b_{0}2^{0}\) 每個「1」都代表該位置的 2 的冪；先知道最左邊是 $2$ 的多少次方，才不會把位值整體推錯一位。

$100110000010110_{2}$ 共有 $15$ 位，所以最左一位是 $2^{15-1}=2^{14}$ 位。

由左至右的位值依次是 $2^{14},2^{13},\dots,2^{1},2^{0}$。

第 2 步
只把「1」的位值加起來

由左數起，數字 $1$ 出現在第 $1$、$4$、$5$、$11$、$13$、$14$ 位，對應位值 $2^{14},\,2^{11},\,2^{10},\,2^{4},\,2^{2},\,2^{1}$：

$$100110000010110_{2}=2^{14}+2^{11}+2^{10}+2^{4}+2^{2}+2^{1}$$

「0」的位置不必寫，因為 $0\times 2^{k}=0$。

第 3 步
把 $2^{10}$ 及以上的項抽出 $2^{10}$
指數律（提取公因數） \(2^{14}=2^{4}\cdot 2^{10},\qquad 2^{11}=2^{1}\cdot 2^{10}\) 選項都以 $2^{10}$ 為單位，所以把 $2^{10}$ 及以上的項統一寫成「某數 $\times 2^{10}$」，才能直接對照。

$$2^{14}+2^{11}+2^{10}=\bigl(2^{4}+2^{1}+2^{0}\bigr)\times 2^{10}$$

而 $2^{4}+2+1=16+2+1=19$，所以這部分等於 $19\times 2^{10}$。

第 4 步
低位部分直接加

餘下的三個「1」在 $2^{4}$、$2^{2}$、$2^{1}$ 位：

$$2^{4}+2^{2}+2^{1}=16+4+2=22$$

因為 $22<2^{10}$，這部分無法再抽出 $2^{10}$，正好就是餘數 $b$。

第 5 步
合併兩部分，再用十進位核對

$$100110000010110_{2}=19\times 2^{10}+22$$

核對：$19\times 1024+22=19456+22=19478$；另一方面 $16384+2048+1024+16+4+2=19478$ ✓

對應選項 A。

易錯：把 $15$ 位當成最高位是 $2^{15}$，全條式便會大一倍，可能誤選 C 或 D；另外低位 $2^{4}+2^{2}+2^{1}=22$ 常被算成 $44$（重複加了一次 $2^{2}$），那就是 B、D 的來源。

答案A（$19\times 2^{10}+22$）
練習 同類新題
題目. 把 $110010000010110_{2}$ 寫成 $a\times 2^{10}+b$ 的形式，其中 $0\le b<2^{10}$。
顯示題解
第 1 步. 共有 $15$ 位，最左一位是 $2^{14}$ 位；「1」在 $2^{14},\,2^{13},\,2^{10},\,2^{4},\,2^{2},\,2^{1}$ 位。
第 2 步. 抽出 $2^{10}$：$2^{14}+2^{13}+2^{10}=\bigl(2^{4}+2^{3}+2^{0}\bigr)\times 2^{10}=25\times 2^{10}$。
第 3 步. 低位：$2^{4}+2^{2}+2^{1}=16+4+2=22<2^{10}$。
第 4 步. 所以 $110010000010110_{2}=25\times 2^{10}+22$。
第 5 步. 核對：$25\times 1024+22=25600+22=25622$；$16384+8192+1024+16+4+2=25622$ ✓
答案：$25\times 2^{10}+22$
