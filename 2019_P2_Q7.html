DSE 2019 · 卷二 · Q7

「或」的複合不等式：取兩段的聯集

不等式 · 複合不等式

題目

滿足複合不等式 $-2(x-5)+5<21$ 或 $\dfrac{3x-5}{7}>1$ 的最小整數是
  1. A$-3$
  2. B$-2$
  3. C$4$
  4. D$5$

題解

第 1 步
先解第一條不等式

$$-2(x-5)+5<21\quad\Longrightarrow\quad -2x+10+5<21$$

$$-2x<6\quad\Longrightarrow\quad x>-3$$

除以負數時不等號要反轉。

第 2 步
再解第二條不等式

$$\frac{3x-5}{7}>1\quad\Longrightarrow\quad 3x-5>7\quad\Longrightarrow\quad x>4$$

第 3 步
「或」代表取聯集
聯集$x>-3$ 或 $x>4$：只要符合其中一條即可，$x>4$ 的整數已包含在 $x>-3$ 之內。

兩段合起來仍是 $x>-3$（因為 $x>4$ 是 $x>-3$ 的一部分）。

第 4 步
找最小整數
小心邊界$-3$ 本身不符合 $x>-3$（嚴格不等），下一個整數才是答案。

大於 $-3$ 的最小整數是 $-2$。

易錯：把 $-3$ 當成答案，忘了不等號是「$>$」而不是「$\ge$」。

答案B（$-2$）
練習 同類新題
題目. 滿足複合不等式 $-3(x-1)+4<19$ 或 $\dfrac{2x-1}{5}>3$ 的最小整數是
  1. A$-3$
  2. B$-4$
  3. C$8$
  4. D$9$
顯示題解
第 1 步. 第一條：$-3x+3+4<19\Rightarrow-3x<12\Rightarrow x>-4$。
第 2 步. 第二條：$2x-1>15\Rightarrow x>8$。
第 3 步. 「或」取聯集：$x>-4$。最小整數為 $-3$。
答案：A（$-3$）
