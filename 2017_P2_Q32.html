DSE 2017 · 卷二 · 第32題

$8=2^{3}$，先把兩項化成 $2$ 的冪

數制 · 十六進制 · 指數

題目

$8^{3}+8^{19}=$
  1. A$10000000000010_{16}$
  2. B$20000000000020_{16}$
  3. C$100000000000100_{16}$
  4. D$200000000000200_{16}$

題解

第 1 步
把 $8$ 寫成 $2^{3}$
冪的冪 $8^{3}=2^{9}$，$8^{19}=2^{57}$ $8=2^{3}$，所以 $8^{n}=2^{3n}$。
\[8^{3}=\left(2^{3}\right)^{3}=2^{9}=512,\qquad 8^{19}=\left(2^{3}\right)^{19}=2^{57}.\]
第 2 步
把 $2$ 的冪改寫成 $16$ 的冪
$16=2^{4}$ $2^{9}=2\cdot16^{2}$，$2^{57}=2\cdot16^{14}$ 每 $4$ 個 $2$ 合成一個 $16$，餘下的係數就是該位的數字。
\[2^{9}=2^{1}\cdot2^{8}=2\cdot16^{2},\qquad 2^{57}=2^{1}\cdot2^{56}=2\cdot16^{14}.\] 在十六進制中，$2\cdot16^{2}$ 就是「$16^{2}$ 位寫 2」，即 $200_{16}$； $2\cdot16^{14}$ 就是「$16^{14}$ 位寫 2」，後面補 $14$ 個 $0$。
第 3 步
把兩個十六進制數相加
對位相加 $200000000000000_{16}+200_{16}$ 兩數的非零數字位不同，相加不會進位。
\[2\cdot16^{14}+2\cdot16^{2} =200000000000000_{16}+200_{16} =200000000000200_{16}.\] （$16^{14}$ 位是 $2$，$16^{2}$ 位是 $2$，其餘為 $0$，共 $15$ 個位。） 答案為 D。
選項 A、C 的首位是 $1$，代表 $16^{14}$ 位只有 $1$，與 $2^{57}$ 不符； 選項 B 的末三位是 $020$，相等於 $2\cdot16^{1}$，位置錯了。
答案D（$200000000000200_{16}$）
練習 同類新題
題目. $4^{5}+4^{11}=$（答案以十六進制表示）
  1. A$400400_{16}$
  2. B$4000400_{16}$
  3. C$100000100_{16}$
  4. D$4004000_{16}$
顯示題解
第 1 步. $4^{5}=2^{10}=4\cdot16^{2}$，即 $400_{16}$。
第 2 步. $4^{11}=2^{22}=4\cdot16^{5}$，即 $400000_{16}$。
第 3 步. 相加：$400000_{16}+400_{16}=400400_{16}$，答案 A。
答案：A（$400400_{16}$）
