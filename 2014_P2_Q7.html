DSE 2014 · 卷二 · Q7

分式不等式

題目

$\dfrac{x-3}{x}>0$ 的解為
  1. A$x>0$
  2. B$x>3$
  3. C$x<0$ 或 $x>3$
  4. D$0<x<3$

題解

第 1 步
找出臨界值
分式為零與無定義 \(\dfrac{A}{B}=0\iff A=0\ (B\ne 0)\) 分式的值只會在分子為零或分母為零的地方變號，先找出這兩個點。
分子的零點： \[ x-3=0\ \Rightarrow\ x=3. \] 分母的零點： \[ x=0. \] 分式在 $x=0$ 無定義，
所以這個點一定不可取。
兩個臨界值把數線分成三段：$x<0$、$0<x<3$、$x>3$。
第 2 步
逐段檢查正負
符號判定 \(\dfrac{A}{B}>0\iff A,B\ \text{same sign}\) 商為正等於分子、分母同號，用這個條件逐段檢查最快。
在每一段取一個代表值代入： \[ x=-1:\ \dfrac{-4}{-1}=4>0\ \text{(true)}, \] \[ x=1:\ \dfrac{-2}{1}=-2<0\ \text{(false)}, \] \[ x=4:\ \dfrac{1}{4}>0\ \text{(true)}. \] 所以只有最左與最右兩段符合。
第 3 步
寫出解集
解集的寫法 \(x<0\ \text{or}\ x>3\) 兩段都符合，且兩個臨界值都不可取，所以用「或」把兩段併起來。
解為 \[ x<0\quad\text{or}\quad x>3. \] 對照選項，答案為 C。
選項 B 只是分子的零點右側，忽略了 $x<0$ 這一段；
選項 D 的方向剛好相反，那是不等號為負號時的答案。
答案C（$x<0$ 或 $x>3$）
練習 同類新題
題目. $\dfrac{x+2}{x-5}>0$ 的解為
  1. A$x>5$
  2. B$-2<x<5$
  3. C$x<-2$ 或 $x>5$
  4. D$x<-5$ 或 $x>2$
顯示題解
第 1 步. 臨界值：分子 $x=-2$，分母 $x=5$（$x=5$ 不可取）。
第 2 步. 取代表值：$x=-3$ 得 $\dfrac{-1}{-8}>0$；$x=0$ 得 $\dfrac{2}{-5}<0$；$x=6$ 得 $\dfrac{8}{1}>0$。
第 3 步. 故解為 $x<-2$ 或 $x>5$，答案 C。
答案：C（$x<-2$ 或 $x>5$）
