DSE 2016 · 卷二 · Q8

「等根」即判別式等於零

方程 · 二次方程的判別式

題目

設 $k$ 為常數，且二次方程 $x^{2}+kx+8k+36=0$ 有等根，則 $k=$
  1. A$6$
  2. B$12$
  3. C$-4$ 或 $36$
  4. D$18$ 或 $2$

註：部分翻印本選項 C 的負號容易脫落，印成「4 或 36」；判別式的結果是 $-4$ 或 $36$。

題解

第 1 步
對照標準式，寫出 $a$、$b$、$c$
標準式 $ax^{2}+bx+c=0$。此處 $a=1$、$b=k$、$c=8k+36$（常數項要把 $8k+36$ 整體看待）。
第 2 步
用「等根」寫出判別式方程
判別式 $\Delta=b^{2}-4ac=0$ $\iff$ 有等根（重根），圖像與 $x$ 軸只有一個交點（相切）。

$$\Delta=k^{2}-4(1)(8k+36)=0$$

$$k^{2}-32k-144=0$$

第 3 步
解二次方程
十字相乘 $36\times(-4)=-144$、$36+(-4)=32$，故 $k^{2}-32k-144=(k-36)(k+4)$。

$$(k-36)(k+4)=0\quad\Longrightarrow\quad k=36\ \text{或}\ k=-4$$

驗算 $k=36$：方程為 $x^{2}+36x+324=0$，即 $(x+18)^{2}=0$，確有等根 $x=-18$ ✓

驗算 $k=-4$：方程為 $x^{2}-4x+4=0$，即 $(x-2)^{2}=0$，等根 $x=2$ ✓

故答案為 C。

答案C（$k=-4$ 或 $k=36$）
練習 同類新題
題目. 若二次方程 $x^{2}+kx+2k+5=0$ 有等根，則 $k=$
  1. A$5$
  2. B$10$
  3. C$-2$ 或 $10$
  4. D$-5$ 或 $2$
顯示題解
第 1 步. $a=1$、$b=k$、$c=2k+5$。
第 2 步. $\Delta=k^{2}-4(2k+5)=k^{2}-8k-20=0$。
第 3 步. $(k-10)(k+2)=0$，得 $k=10$ 或 $k=-2$，即 C。
第 4 步. 驗算 $k=-2$：$x^{2}-2x+1=0$，$(x-1)^{2}=0$ ✓；$k=10$：$x^{2}+10x+25=0$，$(x+5)^{2}=0$ ✓。
答案：C（$-2$ 或 $10$）
