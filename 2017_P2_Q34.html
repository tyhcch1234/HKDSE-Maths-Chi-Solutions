把 $x$ 消去，化成 $\log_9 y$ 的二次方程

對數 · 聯立方程 · 二次方程

題目

若 \[\begin{cases}\log_{9}y=x-3\\ 2\left(\log_{9}y\right)^{2}=4-x\end{cases}\] 則 $y=$
  1. A$-1$ 或 $\dfrac{1}{2}$
  2. B$1$ 或 $\dfrac{1}{3}$
  3. C$2$ 或 $\dfrac{7}{2}$
  4. D$3$ 或 $\dfrac{1}{9}$

題解

第 1 步
由第一式把 $x$ 表示成 $\log_9 y$
主項變換 $x=\log_{9}y+3$ 兩式都含 $\log_{9}y$，把 $x$ 消去就只剩一個未知數。
由 (1)：$x=\log_{9}y+3$。
第 2 步
代入第二式
代入 $2L^{2}=4-(L+3)$，其中 $L=\log_{9}y$ 代入後右邊變成 $4-\left(L+3\right)=1-L$。
\[2L^{2}=4-\left(L+3\right)=1-L \ \Longrightarrow\ 2L^{2}+L-1=0.\] 十字相乘：$\left(2L-1\right)\left(L+1\right)=0$，故 \[L=\frac{1}{2}\quad\text{或}\quad L=-1.\]
第 3 步
由 $\log_9 y$ 反求 $y$
對數定義 $\log_{9}y=L\iff y=9^{L}$ 選項要的是 $y$，不是 $\log_9 y$，最後一步不能漏。
\[L=\frac{1}{2}:\ y=9^{1/2}=3;\qquad L=-1:\ y=9^{-1}=\frac{1}{9}.\] 所以 $y=3$ 或 $\dfrac{1}{9}$，答案為 D。
選項 A 正是「只解到 $\log_9 y$ 就停手」的結果（$L=\frac12$ 與 $L=-1$ 被當成答案）。
答案D（$3$ 或 $\dfrac{1}{9}$）
練習 同類新題
題目. 若 $\begin{cases}\log_{4}y=x-2\\ 2\left(\log_{4}y\right)^{2}=5-x\end{cases}$，則 $y=$
  1. A$4$ 或 $\dfrac{1}{8}$
  2. B$4$ 或 $\dfrac{1}{4}$
  3. C$2$ 或 $\dfrac{1}{2}$
  4. D$16$ 或 $\dfrac{1}{16}$
顯示題解
第 1 步. $x=\log_{4}y+2$，代入第二式：$2L^{2}=5-(L+2)=3-L$。
第 2 步. $2L^{2}+L-3=0\Rightarrow(2L+3)(L-1)=0\Rightarrow L=1$ 或 $L=-\dfrac{3}{2}$。
第 3 步. $y=4^{1}=4$ 或 $y=4^{-3/2}=\dfrac{1}{8}$，答案 A。
答案：A（$4$ 或 $\dfrac{1}{8}$）
