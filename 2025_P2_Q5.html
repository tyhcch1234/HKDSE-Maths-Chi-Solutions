DSE 2025 · 卷二 · Q5

補上 4，兩邊同時變成完全平方

方程 · 二次方程與配方法

題目

設 $k$ 為常數。解方程 $x^{2}+4x=k^{2}-2k-3$。
  1. A$x=k-3$ 或 $x=-k-1$
  2. B$x=k-3$ 或 $x=-k+1$
  3. C$x=k+3$ 或 $x=-k-1$
  4. D$x=k+3$ 或 $x=-k+1$

題解

第 1 步
左邊配成完全平方
配方法 $x^{2}+bx=\left(x+\dfrac{b}{2}\right)^{2}-\dfrac{b^{2}}{4}$。

$x^{2}+4x=(x+2)^{2}-4$，故方程可寫成

$$(x+2)^{2}-4=k^{2}-2k-3$$

$$(x+2)^{2}=k^{2}-2k+1$$

第 2 步
右邊也寫成平方
完全平方 $k^{2}-2k+1=(k-1)^{2}$。

$$(x+2)^{2}=(k-1)^{2}$$

第 3 步
兩邊開平方
平方根 $X^{2}=Y^{2}\Rightarrow X=\pm Y$，不要漏掉負號。

$$x+2=\pm(k-1)$$

取正號：$x+2=k-1\Rightarrow x=k-3$；取負號：$x+2=-k+1\Rightarrow x=-k-1$。

第 4 步
核對
代入檢驗 把 $x=k-3$ 代回左邊。

$(k-3)^{2}+4(k-3)=k^{2}-6k+9+4k-12=k^{2}-2k-3$ ✓

答案 A。常見錯誤是開平方時只取正根，漏掉 $x=-k-1$。

答案A（$x=k-3$ 或 $x=-k-1$）
練習 同類新題
題目. 設 $m$ 為常數。解方程 $x^{2}+6x=m^{2}-4m-5$。
  1. A$x=m-5$ 或 $x=-m-1$
  2. B$x=m-5$ 或 $x=-m+1$
  3. C$x=m+5$ 或 $x=-m-1$
  4. D$x=m+5$ 或 $x=-m+1$
顯示題解
第 1 步. $x^{2}+6x=(x+3)^{2}-9$，故 $(x+3)^{2}=m^{2}-4m+4=(m-2)^{2}$。
第 2 步. 開平方：$x+3=\pm(m-2)$。
第 3 步. 得 $x=m-5$ 或 $x=-m-1$。
答案：A（$x=m-5$ 或 $x=-m-1$）
