DSE 2019 · 卷二 · 第32題

令 $u=\log x$ 解二次方程，最後記得取負

對數 · 對數方程與代入法

題目

若 $\dfrac{3}{3\log x-2}+7=\dfrac{2}{2\log x+1}$，則 $\log\dfrac{1}{x}=$
  1. A$-3$ 或 $2$
  2. B$-2$ 或 $3$
  3. C$-\dfrac{1}{3}$ 或 $\dfrac{1}{2}$
  4. D$-\dfrac{1}{2}$ 或 $\dfrac{1}{3}$

題解

第 1 步
把 $\log x$ 整體換成 $u$
代入法 \(u=\log x\) 方程中 $\log x$ 一律以同一種樣子出現，換成 $u$ 之後就變成單一未知數的分式方程，可以清分母解二次方程。

令 $u=\log x$，方程變成

$$\frac{3}{3u-2}+7=\frac{2}{2u+1}$$

第 2 步
兩邊乘 $(3u-2)(2u+1)$ 清分母
清分母 \(\dfrac{A}{B}=C\iff A=BC\quad (B\neq 0)\) 一次乘上兩個分母的乘積，就能把三項全部變成多項式，避免逐項通分的計算錯誤。

$$3(2u+1)+7(3u-2)(2u+1)=2(3u-2)$$

同時要記下限制：$u\neq\dfrac{2}{3}$ 及 $u\neq-\dfrac{1}{2}$，否則分母為零。

第 3 步
展開並合併同類項

先算 $(3u-2)(2u+1)=6u^{2}-u-2$：

$$3(2u+1)+7(6u^{2}-u-2)=2(3u-2)$$

$$6u+3+42u^{2}-7u-14=6u-4$$

$$42u^{2}-7u-7=0$$

第 4 步
因式分解求 $u$

$$42u^{2}-7u-7=0\;\Longrightarrow\;7\bigl(6u^{2}-u-1\bigr)=0\;\Longrightarrow\;7(2u-1)(3u+1)=0$$

所以 $u=\dfrac{1}{2}$ 或 $u=-\dfrac{1}{3}$，兩個值都不違反上面的限制。

第 5 步
換回題目要的 $\log\dfrac{1}{x}$
倒數的對數 \(\log\dfrac{1}{x}=\log x^{-1}=-\log x=-u\) 題目問的不是 $\log x$ 而是 $\log\dfrac{1}{x}$，兩者相差一個負號，這一步決定最後答案。

$$\log\frac{1}{x}=-\frac{1}{2}\quad\text{或}\quad\frac{1}{3}$$

對應選項 D。

易錯：解出 $u=\dfrac{1}{2}$、$-\dfrac{1}{3}$ 就直接選 C，忘記取負號；C 正是「未變號」的陷阱選項。

答案D（$-\dfrac{1}{2}$ 或 $\dfrac{1}{3}$）
練習 同類新題
題目. 若 $\dfrac{2}{\log x-1}+\dfrac{3}{\log x+2}=2$，則 $\log\dfrac{1}{x}=$
顯示題解
第 1 步. 令 $u=\log x$，方程成為 $\dfrac{2}{u-1}+\dfrac{3}{u+2}=2$，且 $u\neq 1,\,-2$。
第 2 步. 兩邊乘 $(u-1)(u+2)$：$2(u+2)+3(u-1)=2(u-1)(u+2)$，即 $5u+1=2u^{2}+2u-4$。
第 3 步. 整理得 $2u^{2}-3u-5=0$，因式分解 $(2u-5)(u+1)=0$，所以 $u=\dfrac{5}{2}$ 或 $u=-1$。
第 4 步. $\log\dfrac{1}{x}=-u$，故答案為 $-\dfrac{5}{2}$ 或 $1$。
第 5 步. 驗算 $u=\dfrac{5}{2}$：$\dfrac{2}{1.5}+\dfrac{3}{4.5}=\dfrac{4}{3}+\dfrac{2}{3}=2$ ✓；$u=-1$：$\dfrac{2}{-2}+\dfrac{3}{1}=2$ ✓。
答案：$-\dfrac{5}{2}$ 或 $1$
